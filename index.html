FN tracker site

登録したプレイヤーの大会成績(Fortnite Tracker の Epic Events)を、PRの高い順に並べて見比べられます。

URLの末尾に #p=名前1,名前2 の形で付けると、開いた時にそのメンバーが登録されます。PR・PR順位・今季の獲得PR・獲得賞金・最新大会の順位は、補助スクリプトを入れると、いま選んでいる端末(PC / CS / モバイル)の分が Fortnite Tracker から自動で取り込まれます(バトロワ・ZBの両方。今季の順位も取れます)。入れなくても、各行の「入力」から手入力できます。

自動更新の準備(最初に1回だけ)

  1. ブラウザ(Chrome / Edge / Firefox)に拡張機能「Tampermonkey」を入れます。Chromeでは、拡張機能の管理画面で Tampermonkey の「ユーザースクリプトを許可する」をオンにしてください。
  2. 補助スクリプトを開いて、「インストール」を押します。
  3. このページを再読み込みすると、開くだけで自動で更新されます(「全員を更新」でも更新できます)。
  4. それでもこの案内が消えないときは、このページを開いたまま、ブラウザ右上の Tampermonkey のアイコンを押してください。「FN tracker site 連携」が一覧に出ていてオンなら、スクリプトは動いています。一覧に出ない・アイコンが灰色のときは、手順1の「ユーザースクリプトを許可する」がオフの可能性があります。

補助スクリプトがなくても、各行の「入力」から手入力で使えます。
